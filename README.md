# Bureaut — Onscroll Animations Playground

A playground project for experimenting with scroll-driven animation techniques: parallax, image scaling, hover distortion, and pinned/sticky scroll sections.

[Live](https://eugeneyakovlev.github.io/bureaut-demo/)

*Content from [Balbek Bureau](https://www.balbek.com/vslkvska)

## Tech stack

- [Vite](https://vitejs.dev/) — dev server and build tool
- [GSAP](https://gsap.com/) + ScrollTrigger — scroll-based animation and pinning
- [Lenis](https://lenis.darkroom.engineering/) — smooth scrolling
- [Three.js](https://threejs.org/) — WebGL hover-distortion effect
- [Tailwind CSS](https://tailwindcss.com/) — styling
- [gh-pages](https://www.npmjs.com/package/gh-pages) — deployment to GitHub Pages

## Scripts

```
npm run dev      # start dev server
npm run build    # production build
npm run preview  # preview production build
npm run deploy   # deploy dist/ to GitHub Pages
```
